## Project Overview

Designed a conceptual assistive mechanism to help wheelchair users open sliding doors, following a structured Engineering Design Process (EDP).

The project involved identifying accessibility challenges, conducting market research, defining product requirements, developing alternative concepts and evaluating designs through a decision matrix.

The selected concept incorporated a manually operated crank, a 1:2 gear ratio and a fabric-and-hook mechanism. A CAD model and a preliminary physical prototype were also developed.
